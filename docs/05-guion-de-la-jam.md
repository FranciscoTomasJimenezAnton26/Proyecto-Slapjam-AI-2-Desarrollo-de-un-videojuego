# Guion de la jam, hora a hora

Horas en hora de Madrid. Es una guía, no una obligación: si algo va más rápido, se adelanta.

## Jueves 29 — Del tema al juego jugable
| Hora | Tarea |
|---|---|
| 16:00 | Leer el tema en itch.io/Discord. Releer `01-plan.md` |
| 16:00–16:30 | Elegir el giro del tema (proceso en `01-plan.md`). Decidir título del juego |
| 16:30–19:00 | Claude programa el bucle base con formas: puerta, visitante, swipe, contador de 30, tiempo, penalización, rango final |
| 19:00 | **Primera prueba en el móvil.** ¿Divierte con cuadrados? Si no, se ajusta antes de seguir |
| 19:00–21:00 | Generar la imagen ancla del primer visitante y la escena de la puerta hasta dar con el estilo |
| 21:00–21:30 | Cena |
| 21:30–23:30 | Generar 4–5 visitantes más (versión niño + monstruo). Claude los integra |
| 23:30 | Commit y a dormir. **Dormir es parte del plan** |

**Meta del jueves:** juego completo jugable de principio a fin, aunque sea feo.

## Viernes 30 — Que se vea y se sienta bien
| Hora | Tarea |
|---|---|
| Mañana | Completar 8–10 visitantes. Fondo definitivo |
| | Claude: animaciones de entrada/salida, portazo, caramelos volando, monstruo colándose |
| Tarde | Bombilla del porche, dificultad creciente, ajustar tiempos de rangos jugando |
| | Generar efectos de sonido y meterlos |
| Noche | Pantalla de título y pantalla de rangos ilustradas. **Subir una versión de prueba a itch.io** (borrador) y probarla en el móvil |

**Meta del viernes:** el juego ya se podría entregar.

## Sábado 31 — Pulido y entrega
| Hora | Tarea |
|---|---|
| 09:00–11:00 | Música y voces. Pulido de lo que más chirríe al jugar |
| 11:00–12:00 | Página de itch.io: portada, capturas, GIF, descripción y créditos (`06-pagina-itch.md`) |
| 12:00–13:00 | Subida final, prueba completa en el móvil y en el ordenador. **Entregar a la jam** |
| 13:00–16:00 | Margen para imprevistos. Después del cierre no se puede tocar nada |

## Reglas para no perder la jam
1. **Nada nuevo después del viernes por la noche**, solo pulido.
2. Si algo lleva más de 45 minutos atascado, se simplifica o se quita.
3. Probar en el móvil de verdad al menos una vez cada pocas horas.
4. Hacer commit al terminar cada bloque.
5. Cada vez que uses una herramienta de IA nueva, apúntala en la tabla de créditos de `03-herramientas-ia.md`.
